# Website-with-a-Search-Engine

Author: Ajax Tchakounte

## Project overview

This project is search engine for Giphy that:

- allows users to enter and submit a keyword query
- makes a request to the Giphy API Search Endpoint: api.giphy.com/v1/gifs/search
  based on that keyword query
- receives and parses the response
- displays up to a limif of five images on the page from that response
- the site uses a custom css grid to display the images
- the site is responsive so that it appears good/works well on both desktop and mobile devices
